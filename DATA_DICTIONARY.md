# Opisy zmiennych

| Nazwa zmiennej | Opis | Uwagi |
|---|---|---|
| wiek | Grupa wiekowa respondenta |
| płeć | Płeć respondenta |
| wydział | Wydziały, gdzie studiuje respondent |
| poziom_edukacja | Najwyższy ukończony lub aktualny etap kształcenia respondenta |
| czas_dojazd | Czas dojazdu respondenta na uczelnię | W jedną stronę; w minutach |
| miejsce_zamieszkania | Typ miejsca zamieszkania respondenta |
| współlokatorzy | Grupa osób współmieszkających z respondentem |
| satysfakcja_życie | Ocena poziomu satysfakcji respondenta z życia | Wyżej = większa satysfakcja |
| satysfakcja_nauka | Ocena poziomu satysfakcji respondenta z nauki na studiach | Wyżej = większa satysfakcja |
| satysfakcja_finanse | Ocena poziomu satysfakcji respondenta z sytuacji finansowej | Wyżej = większa satysfakcja |
| satysfakcja_zdrowie_fizyczne | Ocena poziomu satysfakcji respondenta ze zdrowia fizycznego | Wyżej = większa satysfakcja |
| satysfakcja_zdrowie_psychiczne | Ocena poziomu satysfakcji respondenta ze zdrowia psychicznego | Wyżej = większa satysfakcja |
| satysfakcja_relacje | Ocena poziomu satysfakcji respondenta z ogółu relacji międzyludzkich | Wyżej = większa satysfakcja |
| satysfakcja_czas_wolny | Ocena poziomu satysfakcji respondenta z czasu wolnego | Wyżej = większa satysfakcja |
| liczba_bliskich_znajomych | Liczba osób, które respondent uważa za bliskich znajomych |
| częstotliwość_spotkań_znajomi | Częstotliwość spotkań ze znajomymi w czasie wolnym respondenta |
| poziom_wsparcia | Ocena poziomu, w jakim respondent odczuwa wsparcie ze strony innych | Wyżej = większe odczuwane wsparcie |
| status_matrymonialny | Status matrymonialny respondenta |
| relacje_rodzina | Ocena zadowolenia z relacji respondenta z rodziną | Wyżej = większe zadowolenie |
| poziom_stres | Ocena ogólnego poziomu stresu respondenta | Wyżej = większy stres |
| kontrola_życie | Ocena poczucia kontroli respondenta nad własnym życiem | Wyżej = większe poczucie kontroli |
| pomoc_psychologiczna | Częstotliwość korzystania z pomocy psychologicznej przez respondenta |
| aktywność_fizyczna | Ilość aktywności fizycznej podejmowanej przez respondenta | Na tydzień |
| czas_ekran | Ilość czasu spędzanego przed ekranem przez respondenta | Dziennie; niezależnie od celu i rodzaju urządzenia |
| czas_media | Ilość czasu spędzanego korzystając z mediów społecznościowych przez respondenta | Dziennie |
| częstotliwość_niezdrowe_jedzenie | Częstotliwość spożywania niezdrowego jedzenia przez respondenta |
| częstotliwość_napoje_energetyczne | Częstotliwość spożywania napojów energetycznych przez respondenta |
| częstotliwość_wyroby_alkoholowe | Częstotliwość spożywania wyrobów alkoholowych przez respondenta |
| częstotliwość_wyroby_nikotynowe | Częstotliwość korzystania z wyrobów nikotynowych przez respondenta |
| ocena_dieta | Ocena jakości własnej diety respondenta | Wyżej = zdrowsza dieta |
| ilość_snu_tydzień | Średnia liczba godzin snu respondenta w dni robocze | Dziennie |
| ilość_snu_weekend | Średnia liczba godzin snu respondenta w weekend | Dziennie |
| problemy_sen | Ocena poziomu problemów ze snem respondenta | Wyżej = większe nasilenie problemów ze snem |
| ocena_studia | Średnia ocen respondenta z ostatniego semestru |
| czas_nauka | Czas poświęcany przez respondenta na naukę i realizację zadań związanych ze studiami | Tygodniowo |
| koła_organizacje | Liczba kół i organizacji studenckich, w których uczestniczy respondent |
| źródło_utrzymania | Główne źródło utrzymania respondenta podczas studiowania |
| wydatki_podstawowe | Kwota przeznaczana przez respondenta na niezbędne wydatki | Miesięcznie; w zł |
| wydatki_rozrywka | Kwota przeznaczana przez respondenta na rozrywkę i przyjemności | Miesięcznie; w zł |
| ocena_finanse | Ocena sytuacji finansowej respondenta | Wyżej = lepsza sytuacja finansowa |
| czy_pracuje | Informacja, czy respondent pracuje | Zarobkowo, bądź nie |
| forma_pracy | Forma pracy respondenta |
| czas_praca | Czas poświęcany przez respondenta na pracę | Tygodniowo |
| powiązanie_praca | Czy praca respondenta jest powiązana z jego kierunkiem studiów |
