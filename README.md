# Zbiór danych – styl życia i satysfakcja z życia studentów

## Opis

Zbiór danych pochodzi z anonimowej ankiety przeprowadzonej wśród studentów Politechniki Wrocławskiej.

Celem badania była analiza zależności pomiędzy wybranymi aspektami życia studenckiego a poziomem satysfakcji z życia.

Ankieta obejmowała m.in. pytania dotyczące:
- snu,
- odżywiania,
- aktywności fizycznej,
- relacji społecznych,
- nauki,
- sytuacji materialnej,
- zdrowia,
- satysfakcji z życia.

## Dane

Zbiór zawiera **396 odpowiedzi**.

Dane są dostępne w pliku:

`dane.csv`

Każdy wiersz odpowiada jednej odpowiedzi, a każda kolumna reprezentuje zmienną lub odpowiedź na pytanie ankietowe.

Przed publikacją usunięto informacje umożliwiające bezpośrednią identyfikację respondentów, w tym adresy e-mail oraz znaczniki czasu wypełnienia ankiety.

## Wykorzystanie

Zbiór może być wykorzystywany do:
- analizy statystycznej,
- wizualizacji danych,
- projektów naukowych i edukacyjnych,
- budowy i testowania modeli analitycznych oraz uczenia maszynowego.
